# INSIDE
1. 目标人群：18–30岁，有焦虑、空心病、抑郁倾向，对哲学思考感兴趣
2. 核心功能 MVP（最小可行产品）：
  - 情绪日记记录模块
  - 哲学思维推送模块
  - 心理测评与反馈模块
  - AI聊天疏导模块（可后期接入）

页面原型：
🏠 首页（Home）
功能定位：每日哲思 + 推荐内容入口   模块布局：
- 顶部横幅：今日哲学卡片（如“存在先于本质”）
- 推荐内容区：心理文章、冥想音频、哲学短片
- 快捷入口：情绪记录、测评、社区树洞
📓 心情记录页（Mood Record）
功能定位：记录每日情绪，促进自我觉察   模块布局：
- 情绪选择：图标式选择（如开心、焦虑、空虚）
- 情绪评分：滑动打分（1–10）
- 心情日记：文本输入区，可附图
- 历史回顾：查看过去记录趋势图
🧪 心理测评页（Assessment）
功能定位：自我评估与反馈   模块布局：
- 测评列表：焦虑量表、空心病量表、抑郁自评
- 问题答题区：单选/多选题
- 分析报告：图表展示 + 哲学引导语（如“你不是孤独的存在”）
- 历史测评记录：查看过往结果与变化趋势
👤 我的页（Profile）
功能定位：用户成长与个性化设置   模块布局：
- 成长图谱：打卡天数、情绪趋势、哲思完成度
- 我的收藏：喜欢的哲学卡片、文章、音频
- 设置中心：隐私设置、账号管理、意见反馈
